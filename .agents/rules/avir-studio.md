# AVIR Studio — Project Guidelines & Rules

## Project Identity
- **Studio Name**: AVIR Studio
- **Focus**: Музыкальный продакшн, биты и тексты (Рэп, Хип-хоп, Трэп, Дрилл, Уличный стиль).
- **Core Stacks**:
  - Web Studio: Tone.js, Web Audio API, Responsive Modern UI for Mobile & Desktop.
  - Audio Processing: Static FFmpeg, Python/Mido, Google Colab (Demucs, MusicGen).
  - Automation & Telegram: Grammy / Telegraf bot (`bot/avir_bot.js`).
  - Storage: Google Workspace (7 TB) via Colab and cloud sync.

## Code Standards
- Always ensure the web studio works flawlessly on both smartphones (touch controls, responsive viewport) and PC monitors.
- Maintain presets for UK/NY Drill, Hard Trap, Boom Bap, Dark Street.
- All commits are synced automatically to GitHub `asperine94-collab/first-project`.
